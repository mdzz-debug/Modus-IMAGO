# M · Imago 0.1.2

- 自由截图触发后立即定格所有显示器画面，便于捕捉动画、视频和瞬时内容。
- Retina 显示器的定格画面改为按真实背板像素捕获，文字和界面细节不再模糊。
- 定格画面仍保留原有窗口识别、悬停高亮和单击选窗能力。
- 修复定格帧中的 Dock 与实时 Dock 重叠显示的问题。
- 定格完成后使用系统遮蔽层隐藏真实 Dock 和菜单栏，避免其继续响应悬停或点击。
- 截图和录屏选区期间不再隐藏或重新置前 M · Imago 窗口，避免结束后打乱微信等应用的窗口层级。
- 确认窗口截图后仅激活被选中的目标窗口，恢复冻结截图前的选窗置前行为。
- 修复副显示器中的应用进入 macOS 原生全屏后无法选择该屏幕的问题。
- 修复副屏点击穿透后截图会话无法结束的问题。
- 修复选中窗口后 Esc 偶尔无法退出截图的问题，并增加不依赖窗口焦点的按键状态兜底监测。
- 截图和录屏工具栏会避开 Dock；Dock 保持显示并仍可包含在截图中。
- 优化多屏全屏 Space 中遮罩窗口的层级和键盘焦点。

此版本用于验证从 0.1.1 到 0.1.2 的 Sparkle 应用内更新流程。
